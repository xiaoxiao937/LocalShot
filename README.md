# LocalShot

LocalShot 是一款隐私优先的原生 macOS 截屏工具。截图、标注、复制和保存全部在本机完成。

> **源码可见，但不是开源软件。** 本仓库保留全部权利，仅供查看与学习参考；未经作者书面许可，不得复制、修改、分发、商用或制作衍生作品。详见 [LICENSE](LICENSE)。

## 当前功能

- 菜单栏应用
- 区域截图（自动识别窗口或自由框选）与全屏截图
- 可在设置中更换数字键的全局快捷键：默认区域 `⌘⇧1`、全屏 `⌘⇧3`
- 文字、箭头、矩形、画笔、马赛克、裁剪
- 撤销和重做
- 对勾复制 PNG 并完成，下载按钮只保存 PNG
- 自定义保存目录
- 多显示器与 Retina 截图

## 隐私设计

- 无网络权限与网络代码
- 不上传截图
- 不接入分析、广告或崩溃收集 SDK
- 不申请辅助功能、输入监控、麦克风、摄像头或完全磁盘访问
- 默认不自启
- App Sandbox，仅允许用户选择的文件读写
- 不使用私有 macOS API

## 构建

推荐直接使用 Xcode Beta 打开 `LocalShot.xcodeproj`，选择 `LocalShot` Scheme 和 `My Mac` 后运行。

也可以使用命令行打包：

```sh
chmod +x Scripts/build_app.sh
Scripts/build_app.sh
```

生成的应用位于 `dist/LocalShot.app`。

本次修正版压缩包为 `dist/LocalShot-0.1.12-macOS.zip`。

### 0.1.12 隐藏菜单栏后的恢复入口

- LocalShot 继续保持不显示 Dock 图标，顶部菜单栏仍是日常控制入口。
- 新增固定全局快捷键 `⌘⇧0`，即使菜单栏图标被隐藏，也能随时打开设置窗口。
- 从“应用程序”或 Spotlight 再次打开 LocalShot 时，会直接显示设置窗口。
- 正常启动且欢迎页已经完成时，也会主动显示设置窗口，避免应用看似“没有打开”。

### 0.1.11 视觉候选与交互精简

- 提取文字不再自动覆盖剪贴板；识别后打开可选择的结果窗口，支持“复制所选”和“复制全部”。
- 工具栏移除直线和椭圆，顺序改为移动、文字、箭头、矩形、画笔、马赛克、裁剪；数字键 `1–7` 与新顺序一致。
- 颜色选择器改为与工具图标协调的紧凑样式。
- 截图候选区域同时结合系统窗口边界和本地 Vision 视觉矩形检测，可识别并吸附非系统窗口的面板与卡片。
- 多层候选重叠时优先较小、较具体的区域；拖动仍随时切换为自由框选。
- 顶部操作提示和选区尺寸标签会避开菜单栏及屏幕安全区域，不再被上方遮挡。
- 编辑截图时按 Return 或数字键盘 Enter 等效于点击绿色对勾；文字输入期间回车仍优先提交文字。

### 0.1.10 文字缩放与数字选工具

- 选中文字后可拖动右下角控制点调整字号，范围为 10–120 点。
- 完成文字输入后自动切回第一个移动工具，并保持新文字处于选中状态。
- 编辑窗口支持数字键 `1–9` 依次选择移动、直线、箭头、矩形、椭圆、画笔、文字、马赛克和裁剪。
- 文字输入框激活时数字键仍用于正常输入，不触发工具切换。

### 0.1.9 文字拖动

- 使用移动工具点击已有文字会显示选中边框，并可直接拖动到截图内的新位置。
- 点击文字以外的空白区域仍然拖动整张截图窗口。

### 0.1.8 静音完成

- 删除复制成功后主动播放的系统提示音；点击对勾复制并完成时保持静音。

### 0.1.7 文字、关闭与轻量化修复

- 修复导出或复制后文字标注上下倒置的问题，并用独立位图渲染验证文字方向。
- 文字输入改为紧凑的原生材质胶囊；macOS 26 及以上使用 Liquid Glass，旧系统使用系统材质。
- 贴图右上角增加关闭按钮，并支持 Esc 与 `⌘W` 关闭。
- 截图编辑窗口支持 `⌘W`，Esc 仍可取消；文字正在输入时 Esc 只取消本次文字。
- 对勾仅将 PNG 写入系统剪贴板并关闭窗口，不创建截图缓存、历史记录或缩略图文件。

### 0.1.6 截图会话事件修复

- 区域截图改为真正的模态截图会话，遮罩显示期间鼠标与键盘事件不再落到下方应用。
- 透明选区也显式参与鼠标命中测试，点击候选窗口会由 LocalShot 接收并完成截图。
- 增加截图会话级 Esc 监听；即使选区视图暂时不在响应链上，也能可靠取消截图。
- Esc 监听仅在 LocalShot 自己的截图会话内生效，不申请辅助功能或输入监控权限。

### 0.1.5 窗口点击与布局修复

- 工具条改为以截图选区的水平中心线定位；选区较窄时会在两侧等量展开，并继续受屏幕可见范围约束。
- 截图遮罩显式接收应用激活后的首次鼠标点击，窗口候选单击不再被系统吞掉。
- 窗口点击与自由框选改为一次性完成回调，并提高轻微手抖与拖动操作的区分阈值。
- 顶部操作提示与选区尺寸改为独立圆角胶囊，统一字号、间距、阴影和描边。
- 更换移动与文字工具图标，避免空白按钮及本地化成“格式”的文字按钮。

### 0.1.4 编辑与选区交互升级

- 文字工具改为画布内直接输入，支持中文输入法；回车或点击别处提交，Esc 取消。
- 箭头改为圆尾、圆肩与圆尖的一体式实心箭头，更接近微信截图的视觉比例。
- 区域截图会随鼠标自动匹配前台窗口；单击采用窗口边界，拖动则立即切换为自由选区。
- 删除独立的窗口截图菜单、弹窗和快捷键，窗口匹配统一包含在区域截图中。
- 明确按钮语义：绿色对勾复制并结束，下载按钮只保存；删除重复的复制按钮与关联设置。
- 工具条按功能重新分组并按内容自适应宽度；macOS 26 及以上使用原生 Liquid Glass，旧系统使用系统材质回退。

### 0.1.3 方向、移动与清晰度修复

- 修复添加标注后导出底图上下颠倒的问题；底图与标注现在分别使用正确的坐标系合成。
- 默认工具改为手形移动，不再自动启用箭头；截图和悬浮工具条可以一起拖动。
- 选区截图使用 `NSScreen.backingScaleFactor` 计算 Retina 原生像素，不再错误输出 1 倍尺寸。
- 带标注导出先以原始像素无插值绘制底图，再按屏幕点坐标叠加标注。

### 0.1.2 修复与交互升级

- 选区层改为透明实时遮罩，不再先截整屏并缩放成背景，因此框选前不会把桌面柔化。
- 松开鼠标后先隐藏遮罩，再由 ScreenCaptureKit 按选区和显示器原生倍率直接截图。
- 标注画布显示在原选区位置，工具条悬浮在选区旁，交互参考微信截图。
- 工具条改用紧凑图标，包含箭头、形状、画笔、文字、马赛克、裁剪、撤销、复制、保存和完成。
- 新增本地文字识别并复制结果，以及可拖动的置顶贴图模式。
- 编辑预览关闭平滑插值；未标注截图仍直接编码原始像素 PNG。
- 新增完整 macOS 应用图标及 Retina 图标资源。
