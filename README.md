# LocalShot

LocalShot 是一款隐私优先的原生 macOS 截屏工具。截图、标注、复制和保存全部在本机完成。

> **源码可见，但不是开源软件。** 本仓库保留全部权利，仅供查看与学习参考；未经作者书面许可，不得复制、修改、分发、商用或制作衍生作品。详见 [LICENSE](LICENSE)。

## 当前功能

- 菜单栏应用
- 区域截图（自动识别窗口或自由框选）与全屏截图
- 可在设置中更换数字键的全局快捷键：默认区域 `⌘⇧1`、全屏 `⌘⇧3`
- 文字（小 / 中 / 大三档字号）、箭头、矩形、画笔、马赛克、裁剪
- 无损裁剪，范围可恢复；标注可移动、调整、删除，撤销/重做（`⌘Z` / `⌘⇧Z`）
- 本地 OCR：可取消、可编辑结果、选择复制和重试
- 手动滚动长截图：选区内逐屏拼接，可复制或保存 PNG
- 对勾复制 PNG 并完成，成功后显示不抢焦点的轻量提示；下载按钮只保存 PNG
- 自定义保存目录
- 多显示器与 Retina 截图

## 隐私设计

- 无网络权限与网络代码
- 不上传截图
- 不接入分析、广告或崩溃收集 SDK
- 不申请辅助功能、输入监控、麦克风、摄像头或完全磁盘访问
- 默认不自启
- App Sandbox，仅允许用户选择的文件读写
- 不使用私有 macOS API

## 构建

推荐直接使用 Xcode Beta 打开 `LocalShot.xcodeproj`，选择 `LocalShot` Scheme 和 `My Mac` 后运行。

也可以使用命令行打包：

```sh
chmod +x Scripts/build_app.sh
Scripts/build_app.sh
```

生成的应用位于 `dist/LocalShot.app`。

本次本地构建压缩包为 `dist/LocalShot-0.3.13-macOS.zip`（build 45）。编译和静态审计通过不等于真实交互已验收；当前验收规则见 `TESTING.md`，发布阻塞项见 `BACKLOG.md`。

打包与安装：

```sh
/bin/zsh Scripts/package_release.sh
# 先从设置或菜单栏退出旧进程；脚本会拒绝替换运行中的版本。
/bin/zsh Scripts/install_app.sh
```

安装先校验临时副本，再替换 App；失败恢复旧 App，成功后将旧 App 移入废纸篓（若废纸篓不可写，则保留明确路径的备份）。

默认使用本机临时签名。正式发行时，由开发者配置 `LOCALSHOT_SIGN_IDENTITY` 为 Developer ID 证书，并配置 `LOCALSHOT_NOTARY_PROFILE` 为预先存入钥匙串的公证凭据名，再运行打包脚本。只有配置公证后才会向 Apple 提交 App，应用本身仍不联网。

### 0.3.13 长截图浮窗

- 去掉系统标题栏，长截图浮窗与 OCR 面板共用玻璃材质、圆角和关闭按钮。仍可拖动浮窗，续拍、复制和保存流程不变。

### 0.3.12 长截图与方框起笔

- 圈出要滚动的正文，点底栏「长截图」（向下箭头）。回原页面向下滚一小段，留至少四分之一重叠，再点「接一屏」。可以多次续接，最后复制长图或保存 PNG。
- 不自动滚动。尽量避开固定标题栏、动态内容和重复图案。没找到接缝时不修改已拼好的长图。最多 32 屏，成图不超过 2400 万像素或 30,000 像素高。
- 方框起笔跳过尚未成形的草稿重画。画框结束时，取景范围没变就不重新布局工具栏。

### 0.3.11 拖框停顿与开屏闪动

- 拖框用当次鼠标事件的位置，松手只确认已经显示的范围。窗口移动期间不重复摆放工具栏。
- 候选窗口和截图共用一份窗口信息。先准备候选框和冻结画面的首帧，再显示遮罩，不做开屏动画。

### 0.3.10 换行、拖框与复制提示

- 用实际组字状态判断输入法候选，避免空标记范围吞掉 Shift＋回车。普通回车仍完成文字。
- 拖框仍改变取景范围；窗口位置改用同一个冻结屏幕原点计算，不再累积窗口取整误差。
- 复制成功提示的图标和文字在框内一起居中。

### 0.3.9 文字换行与移动范围

- Shift＋回车明确插入换行，不再只交给系统默认按键处理；回车仍完成文字，候选未确认时优先交给输入法。保留文字撤销、自动扩框和末尾空行。
- 圈定后，用移动工具拖动空白处，或按住空格拖动，改为调整截图范围。内容始终来自开始截图时冻结的那张图，点对勾才复制完成。
- 平移保持截图像素尺寸，边缘仍可扩大、缩小；调整范围可撤销，标注跟随原画面位置，不随选框搬走。
- 拖文字、箭头等对象仍编辑对象；钉住的图片仍是独立浮窗，可自由移动。
- 本项替代 0.3.2 的“圈定后移动只搬图片”规则。按用户要求未自动操作截图界面，真实效果待确认。

### 0.3.8 箭头实时预览

- 修复起笔长度为零时直接读取空 `NSBezierPath.bounds` 的异常：此前按下和每次拖动的旧范围计算都可能在终点更新前中断，松手后才显示成品。
- 草稿边界先判空；短至零长度时不请求空草稿刷新，下一次拖动可继续生成预览；拖回起点会清除上一帧。
- 绘制、命中和其他箭头边界查询同样处理空路径；保持原有箭头外观、旧新局部刷新和无损导出，不恢复整屏强制重绘。
- 原生 API 语义依据 [Apple NSBezierPath.bounds 文档](https://developer.apple.com/documentation/appkit/nsbezierpath/bounds)；真实拖动效果仍待用户确认。

### 0.3.7 撤销与工具手感

- 无变化的移动/调整不再占撤销，也不清空已有重做；连续方向键微调从第一步即可撤销，快速按键或长按重复合并为一步，回到原位则移除该空项。
- 点击、切工具、修改样式、进入文字、失焦和其他编辑操作结束微调合并；不用延迟计时器，不产生尚未入栈的修改。
- 箭头、矩形、画笔等绘图工具各自记忆粗细；未设置的工具沿用旧偏好，修改已选对象只影响对象，不改默认值。颜色与字号仍沿用现有偏好逻辑。
- 对已完成文字右键选择“恢复自适应宽度”，从手动定宽回到随内容伸缩；位置、内容、颜色和字号不变，可撤销/重做，不增加底栏按钮，不替换原生输入法菜单。
- 上述为本轮实现，真实操作仍待验收。

### 0.3.6 文字对齐、标注更新与参考箭头

- 输入框不再以整套字体的最大字形包围盒作为单行高度，改用 TextKit 实际排版高度及空行的原生行高；不移动首字落点、正文基线或导出位置。
- 保持候选未确认时同步扩框；每个输入会话复用一套独立测量器，尺寸不变时不强制重复布局，工具栏只更新改变的属性。
- 切换工具、开始/结束文字输入只刷新相关区域；静态文字尺寸使用最多 64 项的会话内度量缓存，贴图合成后释放，不新增磁盘文件或图片缓存。
- 箭头改为参考图的针尖尾、渐宽长杆及尖锐实心三角头；预览、导出、命中和擦除共用同一矢量路径，短箭头同比收缩，不生成零长箭头。
- 这批流畅度、留白和箭头外观尚未进行真实界面验收，不能据源码精简认定卡顿已经消失。

### 0.3.5 候选组字阶段同步布局

- 通过原生 `setMarkedText`、`insertText`、`unmarkText` 和文字变化路径，在最外层输入事务完成后同步更新输入框，不再只依赖已提交文字变化通知。
- 测宽读取当前带属性文字（含尚未确认的拼音/英文组字），保留原生候选与选区；布局后更新输入法字符坐标。
- 输入玻璃仅为不接收输入的背景，普通容器统一管理宿主、滚动区、文档和文本容器尺寸，避免多处自动伸缩互相覆盖。
- 几何变化后约束旧滚动偏移并显示当前插入点，防止窄框阶段留下的偏移把文字藏到可见区域外。
- 用户反馈候选组字扩框已正常；具体输入法、边缘和长文本覆盖仍以 `TESTING.md` 待验收项目为准。

### 0.3.4 文字输入自然伸缩

- 去掉输入框内的大号“输入文字”占位提示，空状态仅保留原生插入光标与紧凑玻璃外壳。
- 自动文字框随内容增宽、删字收窄，到右边界后换行增高；第一字落点保持稳定，高度达到可用空间后滚动，不再因输入而整体左移/上移。
- 手动拖动文本宽度后进入定宽排版；重新编辑保留自动/定宽模式，移动、颜色、字号和撤销历史保留该模式。
- 高度按当前文本布局计算，包含空行和中文组字；不重建输入视图或替换原生输入法候选。

### 0.3.3 统一玻璃浮层

- 工具栏、颜色盘、临时文字输入框、OCR 面板及框选提示/尺寸牌共用同一个材质工厂：macOS 26 原生 Liquid Glass，旧系统和降低透明度使用统一回退。
- 输入与 OCR 正文透明，统一留白与常规字体排版，不再叠加大块实色文本底板；关闭输入后仅保留真实文字标注。
- 框选与编辑边框使用同一套轻微圆角和细亮暗描边，只画界面边线，不裁切或虚化选区内容。
- 框选小提示复用非交互玻璃标签，进入编辑背景时隐藏，不参与逐帧背景镂空，也不接收点击或键盘焦点。
- 所有材质仅属于 UI；原始冻结底片、复制/PNG/贴图合成和系统输入法候选窗保持原逻辑。

### 0.3.2 首次选中即固定内容

以下是历史规则，移动行为已由 0.3.9 改为调整取景范围。

- 第一次单击窗口或完成自由框选，就从原始冻结底片裁切并进入编辑，不再等添加第一个标注才确定截图。
- 移动工具或按住空格拖动内部，仅移动截图显示位置，不改变已选像素、尺寸或取景内容。
- 边缘/控制点仍可明确调整范围，并保留原底片恢复和撤销；沿用设置中的默认工具、颜色、粗细与字号。

### 0.3.1 拖动残影与视觉打磨

- 编辑阶段底层只绘制固定冻结底片与均匀暗层，明亮截图和选区边框只由前景窗口绘制；拖动不再同步重绘第二套镂空和边框。
- 框选及编辑边界使用克制的中性明暗细线；可拖动标注有轻量悬停反馈，对象、整图移动和调整有不同光标。
- 标注颜色先打开十色紧凑色盘，“更多颜色”才打开系统面板；仅记录颜色分量、粗细和字号偏好，不记录图片或标注文字。
- 内联文字输入框透明、细边框，使用与导出一致的常规字体排版；OCR 结果增加自然行距，减少重复说明。原生输入法候选窗不作替换。
- 选中后移除常驻操作说明，调整时显示尺寸；完成、取消、退出入口继续保留。没有新增 Shift 几何约束。

### 0.3.0 侧边识别与操作打磨

- OCR 结果改为截图附近的紧凑面板，根据屏幕剩余空间选择位置，保持原图像素不变；支持编辑、选择复制、重试，关闭后在应用仍活跃时返回编辑。
- 撤销/重做按钮根据历史自动启用，提示将恢复的具体动作，文字输入时使用文字自身的撤销。
- 方向键微调选中标注 1 点，Shift 加大为 10 点；按住空格暂时移动，松开后还原工具，不干扰正常文字输入。
- 贴图支持滚轮/触控板缩放、双击恢复原始大小，关闭入口悬停时更明显；极小/细长图保留可操作的关闭区域而不拉伸原图。菜单栏增加“关闭全部贴图”，不关闭正在编辑的截图。
- 设置收敛为常用设置和帮助支持，使用统一卡片、文字层级和间距；退出按钮固定可见，保留权限、快捷键状态和主动导出诊断。

### 0.2.1 交互与视觉收敛

- 移动工具选中标注时展示其实际样式，可调整颜色和粗细并撤销，不改变新标注默认值。

- 拖动时保持工具栏在同一侧，松手后再根据空间判断上下换位；始终限制在屏幕内。

### 0.2.0 产品收口

- 一张原始底片支持选区、标注、裁剪和恢复范围；保留标注，范围变化可撤销，不再清空编辑成果。
- 所有工具下均可调整截图边界；箭头端点、形状和文字有一致的选中、移动、调整、删除和撤销。

- 截图准备增加超时和取消；睡眠、登录会话或显示器变化会安全收尾；重复打开使用已有进程。
- 设置补齐权限状态、快捷键冲突与回退、运行版本、帮助和主动导出的脱敏本地诊断；工具栏适配小屏和降低透明度。
- 更新打包、安装、当前验收与隐私文档；正式签名、公证和真实交互验收仍是公开发行前置条件。

### 0.1.28 文字拖拽修复与窗口框选

- 已完成的文字在移动、文字工具下均可单击选中并拖动，双击重新编辑；已选中的文字在切换工具后仍可移动和拉宽。
- 文字选中框使用真实排版宽度，拖动右下角时框线和换行同步更新；边缘控制点保持在画布内，重新编辑保留调整后的宽度。
- 自动框选仅使用 macOS 窗口，按前后顺序匹配鼠标下的窗口，移除图像形状检测和会粘住旧窗口的悬停逻辑。

### 0.1.27 文字排版、OCR 与自动框选

- 拖动文字标注的调整点改为改变文本框宽度，文字会自动换行和重排；字号仍由小 / 中 / 大独立控制，不再像图片一样整体缩放。
- OCR 识别转到后台执行，增加进度提示和取消入口；中英文自动检测，结果按阅读顺序排列，避免卡住编辑界面。
- 自动框选优先完整的前台窗口和外层容器，增加悬停稳定逻辑，减少内部按钮、卡片或子区域抢选。
- 发布时清理历史测试包，`dist` 仅保留当前应用和最新安装包。

### 0.1.26 统一冻结画布

- 截图选中并进入标注后持续保留外围遮罩，明确区分截图内容与冻结背景，不再在选中完成后突然恢复普通桌面。
- 拖动整张截图时不再撤掉遮罩；遮罩中的明亮选区、边框与编辑窗口实时同步移动，原位置自动恢复暗色，避免双重叠层。
- 选区跟随采用旧位置和新位置的局部刷新，不在每个拖动事件重绘整块 Retina 屏幕。
- 贴图模式仍会主动结束冻结画布，保持贴图可以独立浮动和正常操作桌面。

### 0.1.25 默认工具与方框编辑

- 设置页新增“截图后默认工具”，默认选择移动；区域截图与全屏截图共用该偏好，并持久化到本机设置。
- 方框完成后保持选中，可直接拖动框内移动，拖动四个角点调整大小；两类变化均进入撤销历史。
- 方框和文字的缩放控制点使用十字光标，明确提示当前操作是调整大小。
- 方框选中态移除额外蓝色虚线，只保留简洁的四角控制点，避免与方框本身形成双重边界。

### 0.1.24 浮窗移动叠层修复

- 使用移动工具拖动整张截图前，立即结束冻结背景模式并移除原选区暗层与边框，只保留正在移动的编辑窗口。
- 移动文字、缩放文字等标注内部操作不会触发该切换，仍在无闪烁的冻结背景上完成。
- 编辑窗口转为普通浮窗层级，避免冻结底片中的原位置与移动后的截图同时形成双重选区。

### 0.1.23 单次整屏冻结

- 改正区域截图的底层模型：快捷键触发后先以原生 Retina 分辨率冻结整屏，候选框识别、自由框选、调整与标注始终基于同一张底片。
- 选区确定后不再调用第二次 ScreenCaptureKit；最终图片直接从原始 `CGImage` 像素裁切，不经过屏幕重采样或编辑预览回录。
- 进入标注时继续显示同一张冻结底片和外围暗层，编辑器与选区像素保持一致，不再发生“实时桌面 → 编辑窗口”的亮度跳变。
- 冻结背景始终禁用鼠标与键盘，应用失焦会由系统自动隐藏；安全超时与全局紧急取消继续保留。

### 0.1.22 无闪烁安全交接

- 参照微信截图的可观察交互，选区的最后一帧保持显示，原生 Retina 区域截图和首个标注在后方完成；编辑器已就绪后才一次性移除交接层，不再露出中间的桌面帧。
- 交接层不是缩放后的屏幕截图，透明选区仍直接显示当前桌面；最终成图仍使用 `sourceRect × backingScaleFactor` 的 ScreenCaptureKit 原生像素，不发生二次采样。
- 为避免再次发生输入锁死，交接开始前必须在 WindowServer 层同时禁用鼠标命中与键盘焦点；独立 2 秒看门狗、ScreenCaptureKit 10 秒超时与全局紧急取消均可强制撤下交接层。

### 0.1.21 Retina 画质紧急修复

- 撤回 0.1.20 中“整屏冻结后本地裁切”的区域截图路径，解决部分屏幕缩放环境下整张图像被二次采样、画面变糊的严重回归。
- 区域截图恢复为根据最终选区，直接按 `NSScreen.backingScaleFactor` 请求 ScreenCaptureKit 原生 Retina 像素，不再经过整屏缩放或本地二次裁切。
- 保留 0.1.20 的文字样式、三档字号、选中边框、`⌘Z` / `⌘⇧Z`、`⌘A` 以及矩形局部刷新优化。

### 0.1.20 标注与文字编辑优化

- 区域截图启动时一次性保留原生 Retina 画面；选区与编辑器使用同一份像素源，不再因绘制第一个矩形或文字而闪过桌面。全屏遮罩仍然在后续处理前先完全释放，不回退输入安全保护。
- 文字输入层改为透明背景和常规字重，最终渲染移除白色内描边；新增小、中、大三档字号，已有文字也可切换。
- 文字输入中支持 `⌘A` 全选，并保留输入框内自身的撤销；标注编辑状态支持 `⌘Z` 撤销和 `⌘⇧Z` 重做。
- 新建标注和单击选中标注后显示清晰的双层选中框；文字移动、缩放与字号变更也进入撤销历史。
- 矩形拖画改为只刷新新旧边缘区域，同时过滤无效的高频采样点，降低全屏选区和编辑器中的掉帧。

### 0.1.19 重复使用与设置恢复

- 根据 macOS 系统日志定位并修复设置页 Auto Layout 的 `NSGenericException`：分隔线和退出区域现在先加入共同视图层级，再激活跨视图约束。
- 设置窗口明确禁止关闭后释放，并在控制器失去窗口时自动重建；冷启动、关闭后重开、`⌘⇧0` 和重复打开应用都使用同一条可恢复路径。
- 区域、全屏和设置快捷键不再因为清理旧截图状态而直接返回；本次按键会先作废未完成操作，然后立即执行用户要求的动作。
- 所有异步截图请求增加代次隔离；旧候选识别或旧截图即使延迟返回，也不能覆盖新的截图状态或打开过期编辑器。
- 构建流程新增无界面设置窗口生命周期审计，连续执行“创建、布局、关闭、再次创建”；发生约束异常或窗口被意外释放时不再生成安装包。

### 0.1.18 紧急安全修复

- 修复 0.1.17 在 ScreenCaptureKit 延迟时可能让全屏截图遮罩永久占用输入、只能重启恢复的严重故障。
- 截图遮罩不再运行应用级 modal event loop，也不再使用 `.screenSaver` 窗口层级；异步截图开始前必须先无条件移除遮罩并恢复光标。
- Esc、`⌘.`、`⌘W`、固定全局恢复键 `⌘⇧Esc`、菜单栏“取消当前截图”和任意 LocalShot 全局快捷键都可以取消当前截图；全局取消也会关闭编辑窗口与贴图，且不受截图处理中状态限制。
- 应用失去焦点时自动取消截图；截图遮罩停留超过 120 秒会强制收尾，ScreenCaptureKit 超过 10 秒无响应也会使任务失效并允许立即重试。
- 新增标准 `⌘Q` 主菜单退出路径；退出前统一取消当前选区和等待中的截图任务。
- 设置页新增“退出 LocalShot”按钮，并明确说明菜单栏应用不会出现在 Dock 或系统“强制退出”列表；该按钮同样会先释放全部截图界面再退出后台进程。
- 构建流程新增截图安全审计门禁；重新引入应用级 modal、`.screenSaver` 遮罩或异步截图前不释放遮罩时，构建会直接失败。
- 0.1.17 已从“应用程序”回退，0.1.18 仅在编译、签名和静态安全审查通过后安装，未运行自动界面测试。

### 0.1.17 选区内直接标注

- 选区成立后默认激活第 4 个矩形工具；数字键 `1–7` 或工具栏按钮只切换当前工具，不再立刻结束选区。
- 任意工具激活时仍可拖动四边和四角调整截图范围；选择移动工具后可拖动选区内部整体移动。
- 在选区内部拖画或点击文字位置后才截取最终范围并进入编辑器，首个矩形、箭头、画笔、马赛克、裁剪或文字落点会被完整保留。
- 截图时保持遮罩连续显示，并从 ScreenCaptureKit 中排除 LocalShot 自身窗口，消除选择文字工具及进入编辑器时的闪烁。
- 文字输入中 Return 或数字键盘 Enter 完成输入，Shift+Return 换行；中文输入法候选仍优先确认候选。

### 0.1.16 文字编辑与复制反馈

- 按 Return、数字键盘 Enter 或点击绿色对勾复制成功后，会短暂显示“已复制到剪贴板”；提示不抢焦点、不发出系统声音，并自动消失。
- 文字输入框会随内容扩展，到达画布可用宽度后自动按字符换行；内容很长时可在输入框内滚动，不再被固定尺寸裁掉。
- 完成输入后可双击已有文字再次编辑；文字工具下单击已有文字也可直接编辑，Esc 取消时保留原内容。
- 再次编辑后仍可移动和缩放文字，撤销可恢复编辑前的文字，预览、复制与下载共用同一套多行排版。

### 0.1.15 选区与工具栏合并

- 单击候选窗口或松开自由框选时，选区立即成立并同时显示完整底部工具栏，不再需要第二次确认才能看到工具栏。
- 工具栏显示后仍可拖动选区内部移动，或拖动四边和四角缩小、扩大选区；工具栏会跟随最终选区重新居中。
- 选择文字、箭头等标注工具后，LocalShot 才按最终选区截取原生分辨率图像，并直接进入所选工具。
- 对勾、下载、文字识别和贴图可以直接从选区工具栏执行；撤销与重做会在真正进入标注后启用。
- Return 与数字键盘 Enter 等效于工具栏对勾，数字键 `1–7` 仍可快速选择工具。

### 0.1.14 单击确认选区

- 选区锁定后，单击选区内部即可确认并进入标注，不再要求双击。
- 在内部按住并拖动仍然移动整个选区；移动距离不足 4 点时才视为单击。
- Return 与数字键盘 Enter 继续支持直接确认选区。

### 0.1.13 可调整选区与清晰边框

- 单击候选窗口或拖出自由选区后不再立刻截图，可继续调整选区。
- 拖动选区内部可整体移动；拖动四边或四角的 8 个控制点可缩小或扩大选区。
- 双击选区或按 Return/数字键盘 Enter 后才进入标注，点击选区外可重新框选。
- 选区使用深色衬底、系统强调色和白色高光组成的双层细边框；进入标注后仍保留一圈轻量强调色边框，在明暗背景上都保持清晰但不过分抢眼。

### 0.1.12 隐藏菜单栏后的恢复入口

- LocalShot 继续保持不显示 Dock 图标，顶部菜单栏仍是日常控制入口。
- 新增固定全局快捷键 `⌘⇧0`，即使菜单栏图标被隐藏，也能随时打开设置窗口。
- 从“应用程序”或 Spotlight 再次打开 LocalShot 时，会直接显示设置窗口。
- 正常启动且欢迎页已经完成时，也会主动显示设置窗口，避免应用看似“没有打开”。

### 0.1.11 视觉候选与交互精简

- 提取文字不再自动覆盖剪贴板；识别后打开可选择的结果窗口，支持“复制所选”和“复制全部”。
- 工具栏移除直线和椭圆，顺序改为移动、文字、箭头、矩形、画笔、马赛克、裁剪；数字键 `1–7` 与新顺序一致。
- 颜色选择器改为与工具图标协调的紧凑样式。
- 截图候选区域同时结合系统窗口边界和本地 Vision 视觉矩形检测，可识别并吸附非系统窗口的面板与卡片。
- 多层候选重叠时优先较小、较具体的区域；拖动仍随时切换为自由框选。
- 顶部操作提示和选区尺寸标签会避开菜单栏及屏幕安全区域，不再被上方遮挡。
- 编辑截图时按 Return 或数字键盘 Enter 等效于点击绿色对勾；文字输入期间回车仍优先提交文字。

### 0.1.10 文字缩放与数字选工具

- 选中文字后可拖动右下角控制点调整字号，范围为 10–120 点。
- 完成文字输入后自动切回第一个移动工具，并保持新文字处于选中状态。
- 编辑窗口支持数字键 `1–9` 依次选择移动、直线、箭头、矩形、椭圆、画笔、文字、马赛克和裁剪。
- 文字输入框激活时数字键仍用于正常输入，不触发工具切换。

### 0.1.9 文字拖动

- 使用移动工具点击已有文字会显示选中边框，并可直接拖动到截图内的新位置。
- 点击文字以外的空白区域仍然拖动整张截图窗口。

### 0.1.8 静音完成

- 删除复制成功后主动播放的系统提示音；点击对勾复制并完成时保持静音。

### 0.1.7 文字、关闭与轻量化修复

- 修复导出或复制后文字标注上下倒置的问题，并用独立位图渲染验证文字方向。
- 文字输入改为紧凑的原生材质胶囊；macOS 26 及以上使用 Liquid Glass，旧系统使用系统材质。
- 贴图右上角增加关闭按钮，并支持 Esc 与 `⌘W` 关闭。
- 截图编辑窗口支持 `⌘W`，Esc 仍可取消；文字正在输入时 Esc 只取消本次文字。
- 对勾仅将 PNG 写入系统剪贴板并关闭窗口，不创建截图缓存、历史记录或缩略图文件。

### 0.1.6 截图会话事件修复

- 区域截图改为真正的模态截图会话，遮罩显示期间鼠标与键盘事件不再落到下方应用。
- 透明选区也显式参与鼠标命中测试，点击候选窗口会由 LocalShot 接收并完成截图。
- 增加截图会话级 Esc 监听；即使选区视图暂时不在响应链上，也能可靠取消截图。
- Esc 监听仅在 LocalShot 自己的截图会话内生效，不申请辅助功能或输入监控权限。

### 0.1.5 窗口点击与布局修复

- 工具条改为以截图选区的水平中心线定位；选区较窄时会在两侧等量展开，并继续受屏幕可见范围约束。
- 截图遮罩显式接收应用激活后的首次鼠标点击，窗口候选单击不再被系统吞掉。
- 窗口点击与自由框选改为一次性完成回调，并提高轻微手抖与拖动操作的区分阈值。
- 顶部操作提示与选区尺寸改为独立圆角胶囊，统一字号、间距、阴影和描边。
- 更换移动与文字工具图标，避免空白按钮及本地化成“格式”的文字按钮。

### 0.1.4 编辑与选区交互升级

- 文字工具改为画布内直接输入，支持中文输入法；回车或点击别处提交，Esc 取消。
- 箭头改为圆尾、圆肩与圆尖的一体式实心箭头，更接近微信截图的视觉比例。
- 区域截图会随鼠标自动匹配前台窗口；单击采用窗口边界，拖动则立即切换为自由选区。
- 删除独立的窗口截图菜单、弹窗和快捷键，窗口匹配统一包含在区域截图中。
- 明确按钮语义：绿色对勾复制并结束，下载按钮只保存；删除重复的复制按钮与关联设置。
- 工具条按功能重新分组并按内容自适应宽度；macOS 26 及以上使用原生 Liquid Glass，旧系统使用系统材质回退。

### 0.1.3 方向、移动与清晰度修复

- 修复添加标注后导出底图上下颠倒的问题；底图与标注现在分别使用正确的坐标系合成。
- 默认工具改为手形移动，不再自动启用箭头；截图和悬浮工具条可以一起拖动。
- 选区截图使用 `NSScreen.backingScaleFactor` 计算 Retina 原生像素，不再错误输出 1 倍尺寸。
- 带标注导出先以原始像素无插值绘制底图，再按屏幕点坐标叠加标注。

### 0.1.2 修复与交互升级

- 选区层改为透明实时遮罩，不再先截整屏并缩放成背景，因此框选前不会把桌面柔化。
- 松开鼠标后先隐藏遮罩，再由 ScreenCaptureKit 按选区和显示器原生倍率直接截图。
- 标注画布显示在原选区位置，工具条悬浮在选区旁，交互参考微信截图。
- 工具条改用紧凑图标，包含箭头、形状、画笔、文字、马赛克、裁剪、撤销、复制、保存和完成。
- 新增本地文字识别并复制结果，以及可拖动的置顶贴图模式。
- 编辑预览关闭平滑插值；未标注截图仍直接编码原始像素 PNG。
- 新增完整 macOS 应用图标及 Retina 图标资源。
